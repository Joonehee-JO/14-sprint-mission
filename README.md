### 프로그램 개요
- 간단하게 커맨드창 명령어로 동작하는 채팅 시스템

### 요구사항 정리
1. 유저 생성
    - 빠른 개발을 위해 사용자는 따로 로그인 수행없이 고유 ID 만 발급받아서 로직 수행
2. 채널 이동
    - 간단히 메모리 상에서만 동작하므로 채널 리포지토리 구현 없이 (1~10) 채널로 이동가능한 것으로 수정

### 시나리오
1. 최초 실행 시 메뉴를 선택하여 이름을 입력 후 아이디 발급받아 시작
2. 아이디를 발급받으면 채널 이동 메뉴를 통해 1~10번 채널을 이동가능
3. 선택한 채널에 입장하여 메시지 입력가능
   - 메뉴를 통해 다른 채널로 이동가능
