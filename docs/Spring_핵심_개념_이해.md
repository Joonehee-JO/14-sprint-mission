### 스프링 원리를 다음의 키워드를 중심으로 정리해보세요.
1. IoC Container 
   - 흐름의 역제어로 프레임워크 특성인데 개발자는 기존 객체 생성과 호출을 주도적으로 했던 것을 스프링에게 위임함으로써 스프링이 이런 흐름을 직접 컨트롤하도록 하였습니다.
2. Dependency Injection
   - 객체를 호출할 때 구현체에 의존하는게 아닌 추상에 의존하여 구현체가 바뀌어도 이를 사용하는 계층에서는 변경이 일어나지 않게하는 방법입니다. 이때 스프링이 스프링 컨테이너에서 구현체들을 빈으로써 관리하며 필요시에 의존성 주입을 해줍니다.
3. Bean
   - 스프링 컨테이너안에 키 밸류 형태로 구현체를 관리할 때 여기에 속한 싱글톤 객체들을 빈이라 부릅니다.
